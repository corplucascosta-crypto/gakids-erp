# G&A Kids ERP

Sistema de Gestão Integrada para loja de roupas infantis.

## Tecnologias
- HTML5, CSS3, JavaScript ES6+
- Bootstrap 5
- Supabase (PostgreSQL)
- PWA

## Como executar
1. npm install
2. npm run dev
3. Acesse https://corplucascosta-crypto.github.io/gakids-erp

## Deploy
- Vercel: vercel --prod
